I'm at the beginning of my career so I have no idea, BUT I thought I'd gather all the advice that I got from people:
- Go one level deeper (credit to: [ThePrimeTimeagen](https://www.youtube.com/@ThePrimeTimeagen)) - to understand how to use the something you have to know how it works / how it was built. Prime :wink: example: web development  - if you want to know how to we a better web dev - learn tech behind it: web browsers / HTTP.  Based on my experience this rule resonates with me. I was learning react-native by building react-native libraries with native modules. The learning curve was steep, but after this writing react-native apps and debugging them was much easier since I learned how react-native works under-the-hood and I know where too look for the problem and what tools to use.
